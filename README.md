🛍️ Customer Shopping Behaviour Analysis

📌 Project Overview

This project focuses on analyzing customer shopping behaviour to understand purchasing patterns, customer preferences, and shopping trends using data analytics.

🎯 Project Objectives

- Understand customer purchasing behaviour.
- Analyze shopping patterns and trends.
- Identify important factors influencing purchases.
- Generate meaningful business insights.
- Provide data-driven recommendations.

🛠️ Tools & Technologies

- Python: Data cleaning and analysis
- SQL (SQLite): Data querying and analysis
- Looker Studio: Interactive dashboard and visualization

📂 Project Files

- Customer Shopping Behaviour Dataset
- Python Data Cleaning Notebook
- SQL Queries
- Dashboard Screenshot
- Project Report (PDF)

📊 Project Workflow

1. Dataset collection
2. Data cleaning using Python
3. Data analysis using SQL
4. Dashboard creation using Looker Studio
5. Insights and recommendations

📈 Dashboard

The interactive dashboard presents customer shopping behaviour through charts and visualizations.

💡 Key Outcomes

The project explores customer purchasing patterns and translates data into useful business insights.
